## Short description

Local MCP server for YouTube metadata, thumbnails, comments, and analytics.

## Long description

YouTube Studio MCP is a local Model Context Protocol server that lets AI assistants help creators manage YouTube workflows. It can read channel stats, list recent uploads, inspect and update video metadata, upload thumbnails, post/list comments, and read YouTube Analytics. It runs locally over stdio, uses the user's own Google OAuth credentials, and keeps tokens on the user's machine.
